# Wi-Fi Debug Toolkit

> 网络卡顿时的本地自救工具。无需网络，30 秒定位问题。

## 快速开始

```bash
bash netdiag.sh
```

## 文件说明

| 文件 | 用途 | 何时用 |
|---|---|---|
| `netdiag.sh` | 一键诊断脚本 | 网络出问题时第一件事运行它 |
| `network-diagnosis-guide.md` | 完整原理 + 操作手册 | 想理解"为什么"或需要手动排查时 |

## 依赖

- macOS 13+
- 无外部依赖，全部使用系统内置命令

## 诊断流程

脚本从物理层到应用层逐层检查（L1→L6）：

```
L1: Wi-Fi 物理层 (信号/MCS/速率/信道)
L2: Wi-Fi 环境 (信道拥挤/AWDL/蓝牙)
L3: 本机配置 (DNS/代理/VPN)
L4: 局域网 (ping 网关)
L5: 互联网 (ping 公网/HTTPS)
L6: 应用层 (DNS速度/HTTP vs HTTPS)
```

每层给出 `[PASS]` / `[WARN]` / `[FAIL]`，最终输出诊断摘要和排序后的修复建议。

## 关键指标速查

| 指标 | 正常 | 警告 | 危险 |
|---|---|---|---|
| MCS Index | ≥ 4 | 2-3 | ≤ 1 |
| TX Rate | ≥ 200 Mbps | 50-200 Mbps | < 50 Mbps |
| 信号 | > -65 dBm | -65 至 -75 dBm | < -75 dBm |
| 网关丢包 | 0% | 1-2% | > 5% |
| HTTPS 耗时 | < 0.2s | 0.2-1s | > 1s 或超时 |
